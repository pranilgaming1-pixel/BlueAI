# BlueAI

BlueAI is an Android assistant prototype built with Kotlin and Jetpack Compose.

## Features
- Blue chat interface and orb
- Speech recognition input (device service)
- Text-to-speech responses
- Screen-capture consent request (screen analysis is not implemented)
- Basic offline rule-based responses

## Build APK
GitHub Actions workflow **Build BlueAI APK** builds a debug APK. Open Actions and download the `BlueAI-debug-apk` artifact after a successful run.

## Limitations
A local language model and screen-vision model are not included yet. This is an early prototype, not a full AI assistant.
